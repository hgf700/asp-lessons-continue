# ASP Lessons Continue

This project is a continuation of our ASP.NET MVC learning series. It includes implementations of key enterprise-level features such as scaffolding, identity, testing, and internationalization.

## Features

- **ASP.NET MVC** – Core framework structure using the Model-View-Controller pattern.
- **Scaffolding** – Rapid code generation for views and controllers.
- **ASP.NET Identity** – User authentication and role-based authorization.
- **Repository and Service Layer** – Clean architecture separation for maintainability and testability.
- **Unit Tests** – Tests for controllers and views using xUnit/NUnit.
- **Localization** – Implemented `IStringLocalizer` for internationalization/multi-language support.
- **Admin Panel** – Dedicated admin views for editing users and managing roles.
- **StartBootstrap Template** – Modern UI built with StartBootstrap layout and components.
